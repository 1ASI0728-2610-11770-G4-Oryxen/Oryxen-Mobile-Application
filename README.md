# Oryxen Mobile Application

Native **Android** app (Kotlin + Jetpack Compose) for the **Oryxen** smart plant-care
platform. Focused on the farmer in the field: sign in and watch live Sensor Lite
telemetry with backend-computed health scores.

## Stack

- Kotlin 2.0 + Jetpack Compose (Material 3)
- MVVM (`ViewModel` + `StateFlow`)
- Retrofit + OkHttp + kotlinx.serialization
- Navigation-Compose

## Project layout

```
app/src/main/java/io/oryxen/mobile/
├─ MainActivity.kt
├─ ui/
│  ├─ OryxenNavHost.kt            # login ↔ dashboard navigation
│  ├─ theme/Theme.kt             # Oryxen Material 3 theme
│  ├─ auth/LoginScreen.kt        # LoginScreen + LoginViewModel
│  └─ dashboard/DashboardScreen.kt  # DashboardScreen + DashboardViewModel (5s polling)
├─ domain/HealthStatus.kt        # health-score → status/color mapping
└─ data/
   ├─ Repositories.kt            # AuthRepository, TelemetryRepository
   └─ remote/                    # Retrofit api, DTOs, SessionManager, OkHttp client
```

## Backend connection

The app targets the local .NET backend through the Android emulator loopback:

```
http://10.0.2.2:5170/api/v1   (10.0.2.2 == host localhost from the emulator)
```

`usesCleartextTraffic` is enabled for local HTTP development only.

## Run

1. Start the backend: `docker compose up -d` + `dotnet run --project src/Oryxen.API` (in `Oryxen-Backend`).
2. Open this folder in **Android Studio** (Ladybug or newer). Let it generate the Gradle
   wrapper and sync (`File ▸ Sync Project with Gradle Files`).
3. Run on an emulator (API 24+). Register or sign in, then tap **+** to push a simulated
   Sensor Lite reading; the dashboard polls every 5 seconds and maps the health score.

> Note: the Gradle wrapper jar is generated by Android Studio on first sync (or run
> `gradle wrapper` if you have a local Gradle install). Library versions are pinned in
> `gradle/libs.versions.toml`.
